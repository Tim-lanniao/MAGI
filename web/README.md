# MAGI 正式前端

`web/` 是 MAGI 的中文单页应用，接入 [API.md](../API.md) 描述的后端。源码在 `web/src`，`npm run build` 把产物输出到 `web/dist`，由 Node 服务直接托管。

## 命令

在项目根目录执行，需要 Node 22。

| 命令 | 作用 |
|---|---|
| `npm run build` | 编译后端并构建前端到 `web/dist` |
| `npm run build:web` | 只构建前端 |
| `npm run typecheck:web` | 前端 TypeScript 类型检查 |
| `npm run preview:web` | 本地预览：真实后端 + 正式前端 + 模拟模型，数据只在内存中 |
| `npm run test:web` | 端到端测试，需设置 `MAGI_BROWSER`，可选 `MAGI_SHOTS` 保存截图 |

### 本地预览

```sh
npm run preview:web
```

终端会打印地址，默认端口 5199，可用 `PREVIEW_PORT` 修改。打开 `http://localhost:5199/__preview/login` 免 Passkey 进入。预览会预置 9 条示例表决，覆盖已决定、已复盘、待确认、停机检查、两家缺席、长背景文本和两道联网题，其中一道信源高度重叠。设置页可在两个模拟模型和各自的思考档位之间切换。加 `-- --empty` 可从空数据开始，查看首次使用和空状态。

预览走 http，浏览器无法完成绑定 `https://localhost` 的 Passkey 验证，因此只提供免密入口；邀请注册页 `/__preview/invite` 可以查看界面。预览服务在本机把请求的 `Origin` 改写为后端要求的 `https://localhost`。这些预览专用代码只在 `web/scripts/preview.mjs` 里，不进入正式构建。

模拟模型不会访问外部服务，在问题里写以下标记可以触发对应情景。

| 标记 | 情景 |
|---|---|
| `[双是]` `[双否]` `[分歧]` | 指定两家的票，`[分歧]` 时 GPT 投是、DeepSeek 投否 |
| `[缺席]` | DeepSeek 连接失败，自动重试后记为缺席 |
| `[全缺席]` | 两家首轮都失败，手动技术重试后成功 |
| `[致命]` | GPT 提出一条致命风险，配合「不可逆」触发停机检查 |
| `[慢]` | 模型约 25 秒后才返回，用于观察等待页 |
| `[重叠]` | 打开「需要联网」时，两家引用的网站重叠 2/3，结果标注「两方信源重叠，独立性低」 |

联网题的模拟来源只用保留域名 `example.com`、`example.org`、`example.net`。

真实 Passkey 流程用 `npm run test:web` 验证，它在临时 HTTPS 域名 `magi.test` 上使用浏览器的虚拟验证器。

## 页面

| 路径 | 内容 |
|---|---|
| `/setup?token=…` | 邀请注册 Passkey，进入页面后立即从地址栏移除令牌 |
| `/login` | Passkey 登录，`next` 参数记录登录后返回的页面 |
| `/` | 新决策：问题材料（发送给两家）与我的票（只保存在 Mac）分栏填写，「需要联网」开关默认关闭。我的票可选填最多 8 条来源（网址与论点），不参与信源对比。顶部列出待处理的表决 |
| `/ask?parent=ID` | 带新信息追问，带入原问题材料，新增信息至少 10 字；联网开关不继承原题 |
| `/q/ID` | 一次表决的全过程：等待揭晓、停机检查、本人确认、双缺席重试、最终决定、三方票、少数派理由、风险检查、成立前提、事后复盘、问题材料。揭晓后两家席位显示供应商标志和实际使用的模型名。联网题在票卡里列出来源论点与网页链接，并有信源对比：共同网站数、重叠比例和 2/3 阈值，达到阈值时在结论处标注「两方信源重叠，独立性低」 |
| `/history` | 按月分组的记录，游标分页加载更早的表决 |
| `/stats` | 三方准确率、平均置信度与校准图，附数据表 |
| `/settings` | 设置：两家的模型与思考强度（下次表决生效）、Passkey 列表、重命名、删除与退出登录。旧地址 `/devices` 打开同一页面 |

## 实现约定

- 不依赖前端框架。`src/dom.ts` 提供极简的元素构造函数，每个页面是一个返回元素的函数，离开页面时通过 `AbortSignal` 取消请求、轮询和计时器。
- 后端的 CSP 只允许同源脚本、样式、图片和字体，不允许内联样式与 `data:` URI。因此样式全部写在 `src/styles.css`，动态数值通过 CSSOM 设置 CSS 变量，构建时 `assetsInlineLimit` 为 0，字体使用系统中文字体。
- `/api/auth/me` 每分钟限 10 次，只在整页加载时调用一次。其他请求遇到 401 时统一跳转登录页并保留原路径。
- 表决进行中每 3 秒轮询一次，页面在后台时暂停，回到前台立即刷新，网络失败时退避重试。
- 草稿保存在本浏览器的 `localStorage`，提交成功或手动清空后删除。投票文本按 Unicode 码点计数，与后端一致。
- 视觉：深色指挥终端风格，灵感来自动画中的「三机表决系统」，但结构与用语是自有的。结果页顶部是三席表决面板：本人在上，GPT 与 DeepSeek 在下，中央六边形显示决议（是、否、审议、停机、裁定、流会）。琥珀色是系统信号，青绿表示「是」，信号红表示「否」，致命风险用黑黄警戒斜纹区分。大标题用粗宋体并横向压缩，英文代号用等宽字体；用户写的长文本保持无衬线暖白字，正文行宽约 40 个汉字，行高约 1.9，并开启严格避头尾与中西文间距。只提供深色模式。
